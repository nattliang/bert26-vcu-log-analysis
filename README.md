# BERT26 VCU Log Analysis
This repo contains all the jupyter notebooks for VCU log analysis. It also contains the VCU logs from several test days.

## Setup and Usage

With Python installed, open a terminal in the repository folder and install the required packages:

```bash
python -m pip install jupyter pandas numpy matplotlib
```

Start Jupyter:

```bash
jupyter notebook
```

Open the notebook you want to use, update the log folder and run number in its settings cell, then select **Run All** to generate the plots and analysis.
